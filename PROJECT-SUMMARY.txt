PROJECT MANAGEMENT TOOL - SUMMARY
===================================

WHAT IS THIS PROJECT?
---------------------
A custom project management tool built for internal team use that:
- Tracks daily task assignments and completion across team members
- Uses AI to automatically analyze Slack evening updates and detect task statuses
- Provides a visual dashboard showing who did what, what's pending, and what's blocked
- Integrates with Asana for two-way task syncing
- Generates formatted Slack task lists for daily standups

MAIN MOTIVE
------------
The team posts morning task assignments and evening updates in Slack every day.
Manually tracking who completed what, who's blocked, and who didn't report is tedious.
This tool automates that process using AI (Groq/OpenAI/Gemini) to parse Slack messages
and generate a structured daily report.

HOW IT WORKS (DAILY FLOW)
--------------------------
1. Morning: Team lead posts task assignments in Slack (e.g., "@Rajvir - fix mic issue, @Vishal - color bug")
2. Evening: Each team member posts their update ("Done: fixed mic issue, In Progress: avatar bug")
3. User pastes both messages into the AI Analysis page
4. AI analyzes evening updates against morning assignments
5. System generates a person-by-person breakdown:
   - Who completed what
   - What's still pending/in-progress
   - What's blocked
   - What wasn't mentioned at all
6. Results are saved and displayed on the Daily Status page with date navigation

TECH STACK
----------
Frontend: React 18 + TypeScript + Vite (runs on localhost:5173)
Backend:  Go (Golang) REST API with Gorilla Mux (runs on localhost:8080)
Database: PostgreSQL via Supabase (hosted, free tier)
AI:       Groq API (default, free tier) / OpenAI / Google Gemini
Styling:  Custom CSS with glass-morphism design

FEATURES BUILT SO FAR
----------------------
1. Authentication
   - Google OAuth login
   - JWT token-based API auth
   - Dev mode bypass for local development

2. Dashboard
   - Navigation sidebar with multiple pages
   - Summary cards with task stats

3. AI Analysis Page
   - Two text areas: morning assignments + evening updates
   - "Analyze" button sends both to AI
   - Displays per-task status with confidence scores
   - "Save" button stores results to database
   - Auto-redirects to Daily Status page after save

4. Daily Status Page (Daily Analysis View)
   - Date navigation (previous/next day, jump to today)
   - Four columns: Completed, Pending, Blocked, Not Mentioned
   - Tasks grouped by assignee under each column
   - Summary cards showing totals

5. Task List Editor
   - Editable task list per person
   - Copy-to-clipboard for Slack formatting

6. Asana Integration
   - Connect via Personal Access Token
   - Import projects and tasks
   - Dynamic Kanban board matching Asana sections
   - Two-way sync (move task in app -> updates Asana)

7. Board View (Kanban)
   - Drag & drop tasks between columns
   - Columns dynamically loaded from Asana sections
   - Task cards with priority, assignee, due date

DATABASE TABLES
----------------
- users: team members with roles
- projects: linked Asana projects
- tasks: individual tasks with status, assignee, section
- daily_analyses: saved AI analysis results per date
- daily_tasks: individual task records from analysis (assignee, status, confidence)
- next_day_tasks: carry-over tasks for next day planning
- asana_sections: dynamic Kanban columns from Asana
- slack_analysis_results: Slack vs Asana comparison data

API ENDPOINTS (KEY ONES)
-------------------------
POST /api/ai/analyze-manual     - Analyze pasted morning + evening messages
POST /api/daily-tasks/save      - Save analysis results to database
GET  /api/daily-tasks/{date}    - Get saved tasks for a specific date
GET  /api/tasks                 - List all tasks
POST /api/asana/import          - Import from Asana
GET  /api/asana/sections/{id}   - Get project sections for Kanban
